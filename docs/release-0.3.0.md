# Sequence 0.3.0 预览版

原先只有索引的题目已补为可运行训练。16 套题单共有 671 道去重题目，全部包含 Python 训练模板、参考实现、题解和记忆提示；其中 487 道还提供 JavaScript 参考实现。加上原有独立练习，应用共有 673 道可运行训练。

- 公司题单：华为 71 题、字节跳动 52 题、腾讯 50 题、美团 34 题，来源为 Onefly 公开面经与备考清单。分类展示出处，不代表企业官方题库或出题概率。
- 手机无需判题服务器即可运行内置 Python、JavaScript 和两道 SQL 训练。SQL 使用随包附带的 SQLite WASM；Java/C++ 继续支持自定义判题接口。
- 增加多级链表、循环链表、序列化、读数组接口、随机抽样和多解题的适配；运行示例不代表原站完整判题或复杂度证明。
- 原有草稿、收藏、笔记、手动完成记录与训练历史沿用原 ID。公司题单之间共享进度。
- 题解支持本地公式排版，代码与派生解释保留 MIT 或 CC BY-SA 4.0 来源许可，具体见 NOTICE。

验证：53 项自动化测试通过；全部 671 份 Python 参考实现通过实际 Pyodide WASM 运行；9 条桌面与手机浏览器流程通过。Android APK 构建与签名检查通过，手机交互使用浏览器移动视口验证，未进行 Android 真机测试。

Windows：解压 ZIP 后运行 Sequence.exe，保留同目录文件。Android：安装 APK；本次预览包沿用之前的调试签名，versionCode 提升为 3。模型 API 仍由用户自行配置。自动多端同步与托管判题服务不包含在本次版本中。
