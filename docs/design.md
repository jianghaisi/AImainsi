# 本次设计约定

用途：面向算法与研发求职者的个人面试训练工作台。
用户指定明日方舟风味，使用 design-style-library 的「强风格化游戏终端」文字配方进行原创 UI 实现；未将其当作官方设计规范，也未声称完成原图复刻。
深墨色导航、灰白内容面板、橙色主操作，粗窄英文标题与可读中文正文；编号、细线、硬边切角用于层级。原创抽象轨道图形表达训练进度，不使用游戏角色、商标或原作控件。
首次进入采用 180ms opacity/translateY(6px)；按钮 140ms 颜色反馈，界面状态立即更新。prefers-reduced-motion 下取消位移动画。输入与阅读区域保持稳定。
交付：本地全栈应用、可持久化数据、可配置来源与模型、运行验证记录。所有示例和未验证结果明确标识。
