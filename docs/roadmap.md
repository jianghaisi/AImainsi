# 架构与路线

## 首版已经实现

```text
React 界面 / 共享题库 / 共享学习规则
  ├─ Windows Electron → 本机 Express → SQLite + 系统密钥加密
  └─ Android Capacitor → 本地 API 适配层 → IndexedDB + Android Keystore

两端代码执行：Web Worker → JavaScript / Pyodide WASM Python
两端可选联网：用户模型 API / 用户判题 API / 题库源
```

Python 标准库与 WASM 随安装包分发，不依赖云端运行器。代码草稿保存于设备本地。浏览器 Worker 将代码与界面线程隔开，并提供 30 秒中止机制；它不是供不可信第三方租户使用的安全判题容器。

共享部分包括问题种子、语言实现、配置校验、复习间隔、成长统计；桌面与移动端适配层负责各自存储、网络、文件选择和导出。

## 下一阶段：设备验证与发布

- 多款 Android 真机验证 WebView、输入法、低内存场景与 Python 冷启动。
- 正式签名、版本迁移、备份恢复、无障碍和更完整的错误恢复。
- 判题适配器与隔离容器，支持 Java/C++ 及更多语言。
- 更多原创题解、测试覆盖，来源质量和面经时效标记。

## 有服务器之后：可选联网服务

- 自托管判题服务作为独立能力，可单独配置；无须先搭账号和同步。
- 多端同步增加实体 ID、修改时间、删除标记、增量游标与冲突处理，不能简单覆盖整份数据库。
- 简历、对话、练习、复习进度可选择同步，密钥默认留在各设备；用户显式开启后才上传个人资料。
- 网页客户端复用界面和业务规则；后端提供鉴权、限流、存储与同步 API。
- 离线修改进入队列，恢复网络后同步；建立数据迁移、导出和删除能力。

以上为路线，不是首版已经具备的云功能。手机无需等服务器建设完毕就能安装与练习。
